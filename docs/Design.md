# 디자인 철학

이 문서는 Weatherpane의 시각적 정체성을 정의한다. 모든 UI 결정의 기준이 된다.

## 창의적 방향: 대기의 편집자 (The Atmospheric Editor)

날씨 데이터를 고급 여행 에디토리얼처럼 다룬다. Airbnb의 따뜻함과 한국 미니멀리즘의 정밀함을 결합한다.
사진 중심의 레이아웃, 의도적인 비대칭, 극적인 타이포그래피 스케일로 "템플릿 느낌"을 탈피한다.

---

## 테마 시스템

| 테마        | 이름                    | 분위기                   |
| ----------- | ----------------------- | ------------------------ |
| 밝은 모드   | 햇살 (Haet-Ssal)        | 따뜻한 한지, 편집 갤러리 |
| 어두운 모드 | 달빛 밤 (Dal-Bit Night) | 심층적 몰입, 영화적 야경 |

테마 전환: `<html>` 요소에 `.dark` 클래스 적용/제거로 제어한다.
첫 방문은 `system`으로 시스템 환경설정을 따른다. `system` 선택은 실행 중
시스템 색상 변경도 반영하며, `light`와 `dark`의 명시적 선택은 시스템 변경을
따르지 않는다.

## Settings 화면

Settings는 화면 표시와 접근성 환경을 한 곳에서 편집하는 화면이다. 테마, 온도
단위, 동작 줄이기는 각각 독립된 `fieldset`과 `legend` 안의 단일 선택 라디오
그룹으로 제공한다. 선택된 항목은 활성 상태와 포커스 링으로 분명히 표시하고,
키보드 라디오 조작을 그대로 지원한다.

- 테마는 `system`, `light`, `dark`를 제공한다. `system`은 시스템 색상 변경을
  실시간으로 반영하고 명시적 선택은 그 변경을 무시한다.
- 온도 단위는 `C`, `F`를 제공하며 기본값은 `C`다. 변환은 표시 값에만 적용한다.
- 동작 줄이기는 `system`, `reduced`, `full`을 제공한다. `system`은 시스템의
  동작 줄이기 설정 변경을 실시간으로 따르고, `reduced`와 `full`은 각각 이를
  명시적으로 재정의한다.

세 그룹은 1px 선이나 평면 카드 그림자 없이 배경 표면 변화와 여백으로 구분한다.
로컬 데이터 초기화는 별도의 절제된 파괴적 섹션에 두며, 확인 모달은 삭제할
Weatherpane 데이터 범주를 이름으로 밝히고 취소를 안전한 기본 행동으로 둔다.
모달만 `--radius-lg`와 `--shadow-float`을 사용해 부유 요소임을 표현한다.

## 색상 철학

### 핵심 원칙: "선 없음" 규칙

1px 실선 테두리로 영역을 구분하는 것은 **금지**한다. 경계는 다음 방법으로만 표현한다:

1. **배경색 전환**: `surface-container-low` 카드를 `background` 위에 배치
2. **색조 전환**: 은은한 색상 이동으로 포함 관계 암시
3. **네거티브 스페이스**: 간격만으로 그룹화

### 표면 계층 (밝은 모드)

```text
background (#fcf9f8)                    ← 전체 페이지 기반
  └─ muted (#f0eded)                    ← 보조 섹션
      └─ card (#ffffff)                 ← 우선 카드, 팝오버
```

### 표면 계층 (어두운 모드)

```
background (#131313)                    ← 전체 페이지 기반
  └─ muted (#20201f)                    ← 보조 섹션
      └─ card (#1c1b1b)                 ← 카드
          └─ popover (#20201f)          ← 팝오버, 부유 요소
```

### 오류 상태 의미 색상

홈 설정·연결 오류 화면은 현재 프로젝트 팔레트와 일치하는 Stitch 상세 화면
16번(햇살)·15번(달빛 밤)의 MD3 의미 역할을 사용한다. 기존 shadcn 별칭과 값이
같더라도 역할 이름을 합치지 않으며, 컴포넌트는 아래 토큰의 Tailwind 유틸리티를
사용한다.

| 토큰                               | 밝은 모드 | 어두운 모드 | 용도                              |
| ---------------------------------- | --------- | ----------- | --------------------------------- |
| `--color-on-surface`               | `#1b1c1c` | `#e5e2e1`   | 오류 카드의 주요 제목과 본문 강조 |
| `--color-on-surface-variant`       | `#5c3f41` | `#e5bdbe`   | 오류 설명, 상태 라벨, 보조 문구   |
| `--color-secondary-container`      | `#e3e2e2` | `#8a1f31`   | 오류 화면의 보조 동작 배경        |
| `--color-outline-variant`          | `#e5bdbe` | `#5c3f41`   | 오프라인 상태 표시 점             |
| `--color-primary-container`        | `#e21e4a` | `#ff5169`   | 주요 오류 복구 동작의 호버 배경   |
| `--color-on-primary`               | `#ffffff` | `#68001a`   | 주요 오류 복구 버튼의 전경        |
| `--color-on-secondary-fixed`       | `#1b1c1c` | `#40000d`   | 보조 오류 복구 버튼의 전경        |
| `--color-surface-container-high`   | `#eae7e7` | `#2a2a2a`   | 오프라인 상태 배지 표면           |
| `--color-surface-container-lowest` | `#ffffff` | `#0e0e0e`   | 오류 아이콘의 작은 표면           |

### 주요 색상: Rausch Red

- 밝은 모드: `primary = #ba0036` (진한 빨강)
- 어두운 모드: `primary = #ffb2b6` (밝은 분홍빨강, 어두운 배경 가독성)
- **절제 원칙**: primary는 활성 상태, 긴급 날씨 경보에만 사용한다. 과용 시 임팩트 소멸.

### 보조 색상: 에메랄드

- tertiary 계열은 기상 상태 표시 (좋음/위험)에 사용한다.
- `tertiary = #006a45` (밝은) / `#62dca3` (어두운)
- **참고:** tertiary 토큰은 현재 미구현 상태다. T19 컴포넌트 작업 시 `--color-tertiary` 토큰으로 추가한다.

## 타이포그래피

| 역할                | 밝은 모드         | 어두운 모드       |
| ------------------- | ----------------- | ----------------- |
| 디스플레이/헤드라인 | Plus Jakarta Sans | Plus Jakarta Sans |
| 본문/레이블         | Be Vietnam Pro    | Plus Jakarta Sans |

타입 계층 원칙:

- `display-lg`: 현재 기온, 도시명 (화면 상단 40% 점유)
- `headline`: 섹션 앵커
- `body`: 데이터 수치, 설명
- 크기 간격을 크게 유지한다 — 중간 크기는 위계를 흐린다

## 형태 언어

### 반경 스케일

| 토큰            | 값              | 적용 대상             |
| --------------- | --------------- | --------------------- |
| `--radius-sm`   | `0.5rem (8px)`  | 버튼                  |
| `--radius-md`   | `1.5rem (24px)` | 카드, 에디토리얼 타일 |
| `--radius-lg`   | `2rem (32px)`   | 모달, 대형 패널       |
| `--radius-full` | `9999px`        | 칩, 필터, 알약형 UI   |

### 유리형태 (Glassmorphism)

부유 요소(알림, "지금" 위젯)에 사용:

- 밝은 모드: `surface-container-highest` 60% 불투명도 + `backdrop-blur: 20px`
- 어두운 모드: `surface-bright (#393939)` 40% 불투명도 + `backdrop-blur: 20px`

## 그림자 시스템

"떠있는" 요소(날씨 경보, 모달)에만 그림자를 사용한다. 평면 카드에는 사용하지 않는다.

세 겹 앰비언트 시스템 (`--shadow-float`):

- Layer 1: `0px 2px 4px` — 4% 불투명도
- Layer 2: `0px 4px 12px` — 4% 불투명도
- Layer 3: `0px 10px 24px` — 4% 불투명도

그림자 색상은 순수 회색이 아닌 `on-surface` 기반 색조를 사용한다.

## 금지 사항 요약

| 금지                      | 이유                                     |
| ------------------------- | ---------------------------------------- |
| 1px 실선 테두리           | 프리미엄 에디토리얼 느낌 파괴            |
| 순수 검정 (#000000)       | 유리 효과 소멸, 눈 피로                  |
| 파란색/노란색 날씨 아이콘 | 브랜드 일관성 위반                       |
| 평면 카드에 그림자        | 색상 전환으로 깊이 표현 충분             |
| 100% 불투명 구분선        | 네거티브 스페이스 또는 15% 불투명도 사용 |
